# Version 3 Team User Guide

## Introduction

This guide describes the intended Version 3 experience. **It is an authoring draft, not a tested user procedure.** Use Version 1 for existing demos until Version 3 acceptance completes.

Estimated Time: Pending the first user rehearsal.

### Objectives

* Complete a simple reviewed subscription comparison.
* Save and export only work owned by the signed-in user.

## Intended workflow

1. Open the separately approved Version 3 URL and sign in.
2. Enter or import synthetic RHEL information.
3. Review the source, quantities, price basis, Oracle Linux comparison, and assumptions.
4. Resolve missing information and calculate the supported periods.
5. Save, reopen, and export the reviewed result.

The exact URL, buttons, and screenshots are pending. Do not use the copied Version 1 address as the Version 3 endpoint.

## Current limits

The reviewed upstream app uses a shared demo identity. Its newer scenario supports 12/36 months, while five-year support is planned. AI extraction and scenario import are separate workflows. CSV parity and an owner-filtered list need adaptation and verification.

These gaps must close before this guide can describe the target workflow as available.

## Help and maintenance

Use the workshop's [authoring status](authoring-status.md) for open items. The approved support alias and backup maintainer are pending. Do not share passwords, private keys, or customer data when reporting a problem.
