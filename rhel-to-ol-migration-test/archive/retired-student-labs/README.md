# Retired Student Labs

The Oracle Linux SME review requested removing the former Student Labs 8 through 12 and using OS Management Hub exercises after the migration and kernel labs. These original lab folders are preserved for reference and are not part of either active workshop menu:

- `maintain-packages`: former Lab 8, Maintain Oracle Linux Packages.
- `apache-troubleshooting`: former Lab 9, Configure and Troubleshoot Apache.
- `application-security`: former Lab 10, Manage Application Security.
- `application-backup`: former Lab 11, Back Up and Restore the Application.
- `health-automation`: former Lab 12, Automate Application Health Checks, including its helper script.

Their original lab numbers and references describe the retired sequence. Do not follow them as the current workshop. The active replacements are:

- [Lab 8: Prepare OS Management Hub](../../osmh-prepare/osmh-prepare.md)
- [Lab 9: Register the on-premises client](../../osmh-register-client/osmh-register-client.md)
- [Lab 10: Patch and verify with OSMH](../../osmh-patch-verify/osmh-patch-verify.md)

No server, agent, or OCI resource was changed or removed when these documentation folders were archived.
