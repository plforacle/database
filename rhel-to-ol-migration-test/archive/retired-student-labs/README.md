# Retired Student Labs

The Oracle Linux SME review requested removing the separate migration-validation lab and the former package, Apache, security, backup, and automation labs. These original lab folders are preserved for reference and are not part of either active workshop menu. Numbers below describe the sequence before these removals:

- `validate-cleanup`: former Lab 5, Validate the Migration, including its validation helper.
- `maintain-packages`: former Lab 8, Maintain Oracle Linux Packages.
- `apache-troubleshooting`: former Lab 9, Configure and Troubleshoot Apache.
- `application-security`: former Lab 10, Manage Application Security.
- `application-backup`: former Lab 11, Back Up and Restore the Application.
- `health-automation`: former Lab 12, Automate Application Health Checks, including its helper script.

Their original lab numbers and references describe the retired sequence. Do not follow them as the current workshop. [Lab 7: OS Management Hub Quickstart on OCI](../../osmh-oci-quickstart/osmh-oci-quickstart.md) has been restored to the active workshop.

No server, agent, or OCI resource was changed or removed when these documentation folders were archived.
